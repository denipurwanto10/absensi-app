# 📋 Absensi App

Aplikasi absensi berbasis web yang dikembangkan menggunakan **Laravel** untuk memudahkan pengelolaan data kehadiran karyawan.

## ✨ Fitur

- Login & Logout
- Dashboard
- Manajemen User
- Manajemen Departemen
- Absensi Masuk & Pulang
- Riwayat Absensi
- Laporan Absensi

## 🛠️ Teknologi

- Laravel
- PHP
- MySQL
- Bootstrap

Project ini dibuat sebagai media pembelajaran dan pengembangan menggunakan Laravel.
